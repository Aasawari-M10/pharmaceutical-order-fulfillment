## Project Overview

A hospital or pharmacy places a medicine order.

The platform:

1. Receives the order.
2. Stores the order in Azure SQL Database.
3. Sends order details to Azure Service Bus Queue.
4. Fulfillment Worker processes the order.
5. Updates order status.
6. Allows customers to check order status.
